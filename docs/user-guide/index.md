# User Guide

This guide is for everyone who uses Katta to store and share encrypted data. It covers the Katta Desktop client: how you install it, how you sign in, and how you create and open a vault.

Vault sharing, recovery, and account management happen in Katta Web. Those work as they do upstream, thus the [Cryptomator Hub User Guide](https://docs.cryptomator.org/hub/user-guide/) covers them.
