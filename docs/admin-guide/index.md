# Admin Guide

This guide is for administrators of a Katta Server instance. It covers the storage profiles that decide where users can create vaults, the roles that decide what they can do, and the Admin CLI you configure both with.

:::note
If you also run the instance yourself, see the [Self-Hosting Guide](../self-hosting-guide/index.md) for deployment and storage provider setup.
:::

Users, groups, and vault management work as they do upstream — see the [Cryptomator Hub Admin Guide](https://docs.cryptomator.org/hub/admin-guide/).
